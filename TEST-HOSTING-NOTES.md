# PDF Annotation Test — Hosting Notes

This is a temporary testing copy of [mikispag/pdf-editor](https://github.com/mikispag/pdf-editor), kept here to evaluate its annotation features.

- The upstream project's MIT license is preserved in [LICENSE](LICENSE).
- Original source code remains credited to its upstream author.
- The upstream custom-domain file (`CNAME`) is intentionally not copied.
- The GitHub Actions workflow in `.github/workflows/pages.yml` attempts to deploy this static site to GitHub Pages whenever `main` changes.

If GitHub Pages deployment does not start automatically, open **Settings → Pages** and set the build/deployment source to **GitHub Actions**.

This project processes PDFs locally in the browser, as described by the upstream project. It is an unmodified feature set for testing; no features have intentionally been removed.
